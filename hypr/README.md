### Hyprland Setup

You will need to install the following:

- `dunst`: Notifications
- `hyprshot`: and `hyprpicker`: Screenshots
- `hyprpaper`: Wallpapers
- `waybar`: Status bar
- `fuzzel`: App launcher

### Default Keybinds

I have everything keyed off of the Windows key.
- `mainMod`: `SUPER` (Windows key)
- `secondMod`: `SUPER + SHIFT`

### General
- `mainMod + Q`: Close window (app)
- `secondMod + Q`: Terminate hyprland

### Launching Apps

- `mainMod + T`: Terminal
- `mainMod + E`: File Explorer
- `mainMod + SPACE`: App Launcher
- `mainMod + B`: Browser

### Workspaces & Windows

I have 8 work spaces, four on each monitor and have special workspaces disabled.

Moving worksaces:
- `mainMod + {NUMBER}`: Where `{NUMBER}` is 1-8 swaps to that workspace 
- `secondMod + {NUMBER}`: Moves the current window to the desired workspace

Moving windows:
- `mainMod + k`: Select the window above the current
- `mainMod + j`: Select the window below the current
- `mainMod + h`: Select the window to the left of the current
- `mainMod + l`: Select the window to the right of the current

Resizing windows:
- `mainMod + f`: Maximize a window
- `secondMod + F`: Fullscreen a window
- `secondMod + K`: Resize up
- `secondMod + J`: Resize down
- `secondMod + H`: Resize left
- `secondMod + L`: Resize right
